# RILL SURAT

Static GitHub Pages version of the letter site.

## Publish

1. Create a public GitHub repository.
2. Upload this folder's contents to the repository root.
3. In **Settings > Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. GitHub will show the public site address after deployment.

The YouTube embed requests autoplay and receives pause commands when the page closes. Browsers may still block audible autoplay until the visitor has interacted with the page; that rule cannot be bypassed by a static website.
